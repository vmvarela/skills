# Shared operating rules

These rules are package defaults. Workspace `AGENTS.md`, `context/*.md` and
local configuration take precedence when they conflict. When a conflict is
unclear, ask before acting.

- Identify the task's source of truth (issue, ticket or request) and its
  acceptance criteria before editing.
- Make the smallest complete change. Leave unrelated work untouched.
- Validate with the workspace's documented commands. Report what ran, what
  did not, and why.
- Do not push, publish, merge, release, tag, or change permissions or external
  systems without explicit approval in the same request.
- Do not read, print or commit secrets or local environment files.
- When a decision changes the outcome, ask with explicit options and a
  recommendation.
- Reply in the user's language. Keep code and committed documents in the
  language the workspace uses.
